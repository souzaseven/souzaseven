## 🎯 Sobre Mim

Sou **analista** e estou em transição de carreira para o desenvolvimento **Full Stack**, unindo minha experiência profissional atual com uma paixão antiga por tecnologia e educação.

Acredito que código bem escrito é, acima de tudo, uma ferramenta de impacto: para resolver problemas reais, ajudar pessoas e criar oportunidades de aprendizado.

**O que me move:**
- 💻 Construir soluções que resolvem problemas reais
- 📚 Aprendizado contínuo e educação como caminho de transformação
- 🤝 Projetos que geram impacto na vida das pessoas
- 🚀 Explorar novas tecnologias, incluindo IA aplicada ao desenvolvimento

**Objetivo atual:** consolidar minha base como desenvolvedor Full Stack (PHP, Python e JavaScript), aprofundando frameworks e boas práticas de versionamento para atuar profissionalmente na área.
